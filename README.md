# safARi

## About the Project

safARi is an Augmented Reality based educational application developed using Unity. It enhances traditional learning by allowing users to scan animal images and view interactive 3D models with animations, sounds, and informational content.

The application helps users understand animal characteristics such as habitat, food habits, and behavior through a combination of visual, audio, and interactive elements.

---

## Core Features

### 1. Image-Based AR Recognition

Uses image recognition to scan animal images and display corresponding 3D models in a real-world environment.

### 2. 3D Animal Visualization

Displays realistic 3D animal models to improve understanding of shape, size, and structure.

### 3. Animated Animal Behavior

Includes animations that demonstrate real-life animal movement and behavior.

### 4. Audio-Visual Learning Support

Provides audio narration and sound effects along with educational information such as habitat and food habits.

### 5. User-Controlled Rotation Feature

Allows users to rotate 3D models along the Y-axis for better observation and interaction.

## APK Installation

####### Download Options
- Download from website: https://saf-a-ri-app.vercel.app/

1. Download the APK on your Android device
2. Transfer it to your Android device
3. Enable "Install from Unknown Sources" in settings
4. Install and open the application

### How to Use

1. Open the safARi application
2. Point your camera at a clear image of an animal (from book, flashcard, or poster)
3. Hold your device steady for a few seconds
4. Once detected, a 3D animal model will appear
5. Tap the on-screen button to hear audio narration and sounds
6. Read the displayed details such as name, habitat, and food habits

### Tips for Best Experience

* Use the app in a well-lit environment
* Ensure the entire image is visible in the camera
* Avoid blurry or low-quality images
* Keep your device steady while scanning

### Troubleshooting

* If the animal is not detected, adjust the camera angle
* Move closer or farther from the image
* Ensure proper lighting conditions

## Unity Project 

### Technologies Used

* Unity 3D
* Vuforia Engine
* C#
* Sketchfab (3D models)

### Project Structure

* `Assets/` – Scripts, models, animations, audio, UI
* `Packages/` – Dependencies
* `ProjectSettings/` – Project configuration

### Setup Instructions

1. Clone or download this repository
2. Open the project using Unity Hub
3. Unity will automatically install required packages
4. Build and run on an Android device

### Important Note

* Vuforia Engine is not included in the repository due to size limitations
* It will be automatically installed via Unity Package Manager
